# `profile`

1 method(s) as this deployment serves them. Source: its own `application.wadl`.

## GET /profile/recent/repos

Retrieve a page of recently accessed repositories for the currently authenticated user. Repositories are ordered from most recently to least recently accessed. Only authenticated users may call this resource.
