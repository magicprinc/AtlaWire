# `issueLinkType`

5 method(s) as this deployment serves them. Source: its own `application.wadl`.

## GET /issueLinkType

Returns a list of available issue link types, if issue linking is enabled. Each issue link type has an id, a name and a label for the outward and inward link relationship.

No query parameters.

## POST /issueLinkType

Create a new issue link type.

No query parameters.

## DELETE /issueLinkType/{issueLinkTypeId}

Delete the specified issue link type.

No query parameters.

## GET /issueLinkType/{issueLinkTypeId}

Returns for a given issue link type id all information about this issue link type.

No query parameters.

## PUT /issueLinkType/{issueLinkTypeId}

Update the specified issue link type.

No query parameters.
