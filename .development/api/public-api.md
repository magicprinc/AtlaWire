# Публичное API — как нас видят клиенты

**Справочник:** <https://docs.devino.online/0.2.0/ru/> — «Devino.API — Devino API Reference»,
версия **0.2.0**, язык **ru**. Проверено 2026-11-18: 200, рендерится на клиенте (SPA).

Адрес версионный: `/0.2.0/ru/` — по этой схеме видно, когда появится новая версия (`/0.3.0/…`).
Машиночитаемой спецификации рядом нет: `openapi.json`, `openapi.yaml`, `swagger.json`, `spec.json`
(и их варианты без `/ru/`) отдают HTML той же SPA, не JSON. Значит, снимок возможен только
постранично (браузер/`web_fetch`), а не как файл спеки.

## Как это связано с остальными контурами

Публичный справочник — внешняя граница; внутри одна и та же функциональность живёт в трёх местах:

| контур | что там | как искать |
|---|---|---|
| **Публичное API** (docs.devino.online) | что видит клиент: методы, параметры, ответы | открыть справочник нужной версии |
| **Bitbucket** (`bitbucket.example.com`) | реализация сервисов | `bbk search "<метод/поле>"`, `bbk grep KEY/slug`, `bbk file` |
| **Confluence** (`confluence.example.com`) | описание сервисов, схемы, договорённости | `bbk cql 'text ~ "…"'`, `bbk page <id>` |
| **Jira** (`jira.example.com`) | работы: задачи, дефекты, решения | `bbk jql 'text ~ "…" ORDER BY created DESC'` |

Типовой маршрут вопроса «как это работает у клиента и почему так»:
справочник → (внешнее поведение) → Bitbucket (где реализовано) → Confluence (почему так спроектировано)
→ Jira (кем и когда менялось).

## Использование в bbk

```python
from bbk import find, search_code, search_cql, jql
find(["<название метода API>", "<поле из ответа>"])   # сразу три контура
search_code("<имя метода>")                           # реализация
search_cql('text ~ "<термин>"')                       # описание
jql('text ~ "<термин>" ORDER BY created DESC')        # работы
```

## Обновление

Файл статический: при выходе новой версии API (или изменении текущей) обновите адрес, версию и дату
в шапке. Если понадобится регулярно — расширить `tools/refresh_docs.py` источником типа
`http-page` со снимком HTML (сейчас он умеет только страницы Confluence по pageId).
